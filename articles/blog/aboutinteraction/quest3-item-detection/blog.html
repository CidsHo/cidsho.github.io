利用Quest3头显实现物体识别功能（YOLO v8框架）

首发于 Github

Cids Ho

很简单的实现方式，其实只是将串流的视频当作数据源，然后进行AI检测，最后将检测结果显示在Quest的屏幕上。

2025-03-15更新：Oculus官方时隔数年终于开放了摄像头权限：官方示例，未来可以做一个无需与电脑连接的版本。

硬件要求

  • NVIDIA显卡
  • Meta Quest 3

    • 软件要求

  • Python 3.11.7
  • Unity 2022.3.20f1
  • OBS（开源直播工具）
  • Meta开发者中心（MDH）

    • 实现原理

  • 投屏传输: 通过MDH将Quest的透视画面（视频穿透视图）实时投屏至电脑端。
  • 虚拟摄像头捕获: 使用OBS的虚拟摄像头功能，捕获Quest投屏的透视画面。
  • AI目标检测: 在Python中部署AI模型（本方案采用YOLO v8），对虚拟摄像头捕获的画面进行实时物品识别。
  • 网络通信: 在电脑端的Python程序与Quest端的Unity程序之间建立网络连接（如TCP/UDP）。
  • 数据回传: 将AI检测结果（物品类别、位置坐标等）以JSON格式回传至Quest端的Unity程序。
  • 结果展示: Unity解析JSON数据，在Quest屏幕上叠加显示检测框与标签。

    • 效果展示（上图在低亮度环境中测试，效果一般）.

    限制

  • 无法独立运行:需确保Quest头显与电脑处于同一局域网，且保持MDH投屏连接。
  • 仅支持2D平面分析: AI分析基于投屏的2D画面，无法还原Quest透视模式下的深度信息或3D空间坐标。
  • 易受虚拟物体干扰: 若场景中存在Unity渲染的虚拟物体（如AR叠加的模型），可能干扰真实物品的检测精度。
